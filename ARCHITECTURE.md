## 数据流

```
Heartbeat (15m)
    ↓
Gate Check (OPEN?)
    ↓ YES
Risk Check (PASS?)
    ↓ YES
Message Check → 可能产生任务
    ↓
Task Queue → 取出任务
    ↓
State Machine → 状态: running
    ↓
Planner → 制定计划
    ↓
Executor → 执行一步
    ↓
Watchdog → 监控超时
    ↓
Reflection Engine → 反思
    ├─→ continue → State: running → 继续
    ├─→ adjust   → 产生子任务 → 回到Task Queue
    └─→ stop     → State: finished → Memory
    ↓
Memory System → 保存记忆
    ↓
SLEEP (等待下一次心跳)
```

## 组件职责

| 组件 | 文件 | 职责 |
|------|------|------|
| **Heartbeat** | `core/heartbeat.py` | 定时触发，驱动整个系统 |
| **Gate** | `system/gate.json` | 外部控制开关，安全机制 |
| **Risk** | `tools/*_check.py` | 权限检查，安全守门 |
| **Message** | `system/message_checker.py` | 检查外部输入 |
| **Task Queue** | `tasks/queue.py` | 任务队列+任务树管理 |
| **State Machine** | `system/state.json` | 状态流转管理 |
| **Planner** | `core/heartbeat.py` (内嵌) | 制定执行计划 |
| **Executor** | `tasks/worker.py` | 执行具体步骤 |
| **Watchdog** | `system/watchdog.py` | 超时监控 |
| **Reflection** | `system/reflection_engine.py` | 自我反思 |
| **Memory** | `memory/` | 三层记忆存储 |

## 关键设计原则

### 1. 安全第一
```
Gate → Risk → 其他模块
任何一层FAIL，系统停止自主行为
```

### 2. 一次一步
```
Executor原则: 一次心跳只执行一个步骤
防止阻塞，确保系统响应性
```

### 3. 反馈闭环
```
Executor → Reflection → (可能产生子任务) → Task Queue
形成自我改进的循环
```

### 4. 三层记忆
```
短期: 当前任务状态 (易变)
长期: 知识积累 (持久)
思维: 每次心跳的思考记录 (历史)
```
