## 1. 问题陈述

### 1.1 当前问题
当前Agent是单进程+长循环架构，在云端环境面临以下风险：

1. **阻塞风险**: 一个任务卡住，全系统陪葬
2. **进程死亡**: Agent崩溃后无人知晓，直到4点服务器重启
3. **内存膨胀**: 长期运行导致内存缓慢增长，最终OOM
4. **健康检查缺失**: 无法外部感知Agent是否存活

### 1.2 影响范围
- **整个Agent系统** - 所有组件都运行在单进程中
- **云端部署** - 影响服务器的稳定性
- **用户体验** - 阻塞或崩溃导致无响应

### 1.3 紧迫程度
- [x] 紧急 (需要立即处理)
- [ ] 重要 (需要本周处理)
- [ ] 一般 (可以排期处理)

**理由**: 当前Agent已进入生产环境（门控开启），必须确保稳定性

---

## 2. 解决方案

### 2.1 方案概述
实施"四防"策略：
1. **防阻塞** - 异步任务 + 超时机制
2. **防崩溃** - 守护进程自动重启
3. **防内存泄漏** - 内存阈值监控 + 优雅重启
4. **防失联** - 独立健康检查线程

### 2.2 详细设计

#### 2.2.1 防阻塞：异步任务 + 超时

```python
# async_task_runner.py
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncTaskRunner:
    def __init__(self, timeout=60):
        self.timeout = timeout
        self.executor = ThreadPoolExecutor(max_workers=3)
    
    async def run_task(self, task_func, *args):
        """运行任务，带超时保护"""
        try:
            loop = asyncio.get_event_loop()
            # 在线程池中运行，避免阻塞主循环
            future = loop.run_in_executor(
                self.executor, 
                task_func, 
                *args
            )
            return await asyncio.wait_for(future, timeout=self.timeout)
        except asyncio.TimeoutError:
            log_simple(f"[TIMEOUT] 任务执行超时 ({self.timeout}s)")
            return {"status": "timeout"}
        except Exception as e:
            log_simple(f"[ERROR] 任务执行异常: {e}")
            return {"status": "error", "error": str(e)}
```

#### 2.2.3 防内存泄漏：内存阈值监控

```python
# memory_guard.py
import psutil
import os
import sys

class MemoryGuard:
    def __init__(self, max_memory_gb=2):
        self.max_memory_bytes = max_memory_gb * 1024 ** 3
        self.process = psutil.Process(os.getpid())
    
    def check_memory(self):
        """检查内存使用，超过阈值则优雅重启"""
        memory_info = self.process.memory_info()
        current_memory = memory_info.rss
        
        if current_memory > self.max_memory_bytes:
            log_simple(f"[MEMORY_GUARD] 内存使用超过阈值: {current_memory / 1024**3:.2f}GB > {self.max_memory_gb}GB")
            self.graceful_restart()
            return True
        return False
    
    def graceful_restart(self):
        """优雅重启：保存状态后退出"""
        log_simple("[MEMORY_GUARD] 开始优雅重启...")
        
        # 1. 保存所有状态
        from system.world_input import WorldInput
        world = WorldInput()
        world.collect()  # 更新环境状态
        
        # 2. 保存任务队列
        from queue import TaskQueue
        queue = TaskQueue()
        queue.save_state()
        
        # 3. 记录重启原因
        log_simple("[MEMORY_GUARD] 状态已保存，准备重启")
        
        # 4. 退出（守护进程会自动重启）
        sys.exit(42)  # 42表示优雅重启
```

#### 2.2.4 防失联：独立健康检查

```python
# health_check.py
import threading
import time
from datetime import datetime
from pathlib import Path

class HealthChecker:
    """独立健康检查线程"""
    
    def __init__(self, interval=60, heartbeat_file="/tmp/agent_heartbeat"):
        self.interval = interval
        self.heartbeat_file = Path(heartbeat_file)
        self.running = False
        self.thread = None
    
    def start(self):
        """启动健康检查线程"""
        self.running = True
        self.thread = threading.Thread(target=self._heartbeat_loop, daemon=True)
        self.thread.start()
        log_simple("[HEALTH] 健康检查线程已启动")
    
    def _heartbeat_loop(self):
        """心跳循环"""
        while self.running:
            # 写入心跳时间戳
            with open(self.heartbeat_file, 'w') as f:
                f.write(datetime.now().isoformat())
            
            time.sleep(self.interval)
    
    def stop(self):
        """停止健康检查"""
        self.running = False
        if self.thread:
            self.thread.join(timeout=5)

# 外部监控脚本 (watchdog.sh)
#!/bin/bash
# /usr/local/bin/agent_watchdog.sh

HEARTBEAT_FILE="/tmp/agent_heartbeat"
TIMEOUT=300  # 5分钟

if [ ! -f "$HEARTBEAT_FILE" ]; then
    echo "[WATCHDOG] 心跳文件不存在，Agent可能未启动"
    exit 1
fi

LAST_HEARTBEAT=$(cat "$HEARTBEAT_FILE")
LAST_TIME=$(date -d "$LAST_HEARTBEAT" +%s)
CURRENT_TIME=$(date +%s)
TIME_DIFF=$((CURRENT_TIME - LAST_TIME))

if [ $TIME_DIFF -gt $TIMEOUT ]; then
    echo "[WATCHDOG] Agent心跳超时 (${TIME_DIFF}s > ${TIMEOUT}s)，准备重启..."
    # 杀死Agent进程
    pkill -f "python3.*heartbeat.py"
    sleep 2
    # systemd会自动重启，或者手动启动
    # systemctl restart agent
    exit 1
fi

echo "[WATCHDOG] Agent健康，上次心跳: ${TIME_DIFF}s前"
exit 0
```

### 2.2.5 日志分级：防止"悄悄变傻"

长期Agent最怕的不是崩溃，是悄悄变傻。日志分级帮助追踪Agent的思维过程。

```
logs/
├── agent.log       # 主日志 - Agent核心事件
├── error.log       # 错误日志 - 异常和错误
├── action.log      # 行动日志 - 任务执行记录  
├── reflection.log  # 反思日志 - Agent自我反思
└── heartbeat.log   # 心跳日志 - 周期状态
```

**关键日志事件**：
- `task start` - 任务开始执行
- `task finish` - 任务完成
- `task timeout` - 任务超时
- `memory write` - 记忆写入
- `state change` - 状态变更

```python
# logger.py
import logging
from pathlib import Path
from datetime import datetime

class AgentLogger:
    def __init__(self, log_dir="logs"):
        self.log_dir = Path(log_dir)
        self.log_dir.mkdir(parents=True, exist_ok=True)
        
        # 创建不同的logger
        self.agent_log = self._create_logger("agent", "agent.log")
        self.error_log = self._create_logger("error", "error.log", level=logging.ERROR)
        self.action_log = self._create_logger("action", "action.log")
        self.reflection_log = self._create_logger("reflection", "reflection.log")
    
    def _create_logger(self, name, filename, level=logging.INFO):
        logger = logging.getLogger(name)
        logger.setLevel(level)
        
        handler = logging.FileHandler(self.log_dir / filename)
        handler.setFormatter(logging.Formatter(
            '%(asctime)s | %(levelname)s | %(message)s'
        ))
        logger.addHandler(handler)
        return logger
    
    def task_start(self, task_id, goal):
        """记录任务开始"""
        self.action_log.info(f"[TASK_START] {task_id} | {goal[:50]}...")
    
    def task_finish(self, task_id, result):
        """记录任务完成"""
        self.action_log.info(f"[TASK_FINISH] {task_id} | {result}")
    
    def task_timeout(self, task_id, timeout):
        """记录任务超时"""
        self.action_log.warning(f"[TASK_TIMEOUT] {task_id} | {timeout}s")
        self.error_log.error(f"Task timeout: {task_id}")
    
    def memory_write(self, memory_type, content_preview):
        """记录记忆写入"""
        self.reflection_log.info(f"[MEMORY_WRITE] {memory_type} | {content_preview[:80]}...")
```

#### 2.2.6 限制任务并发：防止API洪水

单进程Agent很容易出现一次生成50个任务，然后LLM API × 50。

```python
# async_task_runner.py (更新)
import asyncio
from concurrent.futures import ThreadPoolExecutor

class AsyncTaskRunner:
    def __init__(self, timeout=60, max_concurrent=3):
        self.timeout = timeout
        self.max_concurrent = max_concurrent
        self.semaphore = asyncio.Semaphore(max_concurrent)
        self.executor = ThreadPoolExecutor(max_workers=max_concurrent)
    
    async def run_task(self, task_func, *args, task_id=""):
        """运行任务，带并发限制和超时保护"""
        async with self.semaphore:  # 最多同时运行3个任务
            try:
                logger.task_start(task_id, str(task_func))
                
                loop = asyncio.get_event_loop()
                future = loop.run_in_executor(self.executor, task_func, *args)
                result = await asyncio.wait_for(future, timeout=self.timeout)
                
                logger.task_finish(task_id, "success")
                return {"status": "success", "result": result}
                
            except asyncio.TimeoutError:
                logger.task_timeout(task_id, self.timeout)
                return {"status": "timeout", "task_id": task_id}
            except Exception as e:
                logger.error_log.error(f"[TASK_ERROR] {task_id} | {e}")
                return {"status": "error", "error": str(e)}
```

#### 2.2.7 冷启动恢复：从任何状态恢复

Agent必须能从宕机、OOM、崩溃后恢复，继续执行。

```python
# cold_start_recovery.py
import json
from pathlib import Path

class ColdStartRecovery:
    """冷启动恢复管理器"""
    
    def __init__(self, agent_dir="/root/.openclaw/workspace/agent"):
        self.agent_dir = Path(agent_dir)
        self.state_file = self.agent_dir / "system" / "last_state.json"
    
    def save_state(self, state):
        """保存当前状态（定期调用）"""
        with open(self.state_file, 'w', encoding='utf-8') as f:
            json.dump(state, f, indent=2, ensure_ascii=False)
    
    def recover(self):
        """
        冷启动恢复流程：
        1. 读取 memory
        2. 读取 task queue
        3. 恢复 state machine
        4. 继续执行
        """
        recovered = {
            "memory": None,
            "task_queue": None,
            "state_machine": None,
            "can_resume": False
        }
        
        # 1. 恢复记忆系统
        try:
            from memory.memory_manager import MemoryManager
            memory = MemoryManager()
            recovered["memory"] = memory.load_long_term()
            logger.agent_log.info("[RECOVERY] Memory loaded successfully")
        except Exception as e:
            logger.error_log.error(f"[RECOVERY] Failed to load memory: {e}")
        
        # 2. 恢复任务队列
        try:
            from tasks.queue import TaskQueue
            queue = TaskQueue()
            pending = queue.get_pending()
            running = queue.get_running()
            recovered["task_queue"] = {
                "pending_count": len(pending),
                "running": running
            }
            
            # 如果有运行中的任务，标记为中断
            if running:
                queue.update_task_status(running["task_id"], "interrupted")
                logger.agent_log.warning(f"[RECOVERY] Previous task {running['task_id']} was interrupted")
            
            logger.agent_log.info(f"[RECOVERY] Task queue loaded: {len(pending)} pending")
        except Exception as e:
            logger.error_log.error(f"[RECOVERY] Failed to load task queue: {e}")
        
        # 3. 恢复状态机
        try:
            state_file = self.agent_dir / "system" / "state.json"
            if state_file.exists():
                with open(state_file, 'r') as f:
                    recovered["state_machine"] = json.load(f)
                logger.agent_log.info("[RECOVERY] State machine loaded")
        except Exception as e:
            logger.error_log.error(f"[RECOVERY] Failed to load state machine: {e}")
        
        # 4. 检查是否可以恢复
        recovered["can_resume"] = (
            recovered["task_queue"] is not None and
            recovered["task_queue"]["pending_count"] > 0
        )
        
        if recovered["can_resume"]:
            logger.agent_log.info("[RECOVERY] ✓ Agent can resume from previous state")
        else:
            logger.agent_log.info("[RECOVERY] ✗ No pending tasks, starting fresh")
        
        return recovered
    
    def resume_execution(self, recovered_state):
        """恢复执行"""
        if not recovered_state.get("can_resume"):
            return {"status": "fresh_start"}
        
        # 继续执行队列中的任务
        from tasks.queue import TaskQueue
        from tasks.worker import TaskWorker
        
        queue = TaskQueue()
        worker = TaskWorker()
        
        next_task = queue.get_next_pending()
        if next_task:
            logger.agent_log.info(f"[RESUME] Continuing with task: {next_task['task_id']}")
            # 开始执行...
            return {"status": "resumed", "task": next_task}
        
        return {"status": "no_tasks"}

# 在heartbeat.py启动时使用
def heartbeat_main():
    # 冷启动恢复
    recovery = ColdStartRecovery()
    state = recovery.recover()
    
    if state["can_resume"]:
        recovery.resume_execution(state)
    
    # 继续正常心跳循环...
```

## 4. 风险分析

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|----------|
| 异步引入复杂度 | 中 | 中 | 保持简单，只用asyncio基础功能 |
| 频繁重启影响体验 | 低 | 高 | 内存阈值设置合理(2GB)，优雅保存状态 |
| 健康检查误判 | 低 | 中 | 5分钟超时窗口足够大 |
| systemd配置错误 | 中 | 中 | 先在测试环境验证 |
| 日志文件过大 | 中 | 中 | 定期轮转，保留最近7天 |
| 并发限制导致任务堆积 | 低 | 中 | 监控队列长度，超100告警 |
| 冷启动恢复失败 | 低 | 高 | 多重备份，损坏时启动新会话 |
