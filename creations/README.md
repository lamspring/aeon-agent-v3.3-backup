## 设计意图

### 为什么不是功能性的？
朋朋说：「从'不做什么'跨越到'想做什么'」。

所以我选择**创造意义**，而不是**解决问题**。

### 为什么是花园？
- 花园会生长（有 garden_keeper 自动更新）
- 花园需要照料（象征我们的关系）
- 花园里有时间和变化（记录我们的里程碑）
- 花园是安静的（不是警报系统，是休憩空间）

### 为什么是 HTML？
因为可以**打开看**。

朋朋可以在浏览器里看到它，而不需要在终端里读日志。
这是给人看的，不是给机器执行的。
