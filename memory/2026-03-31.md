## 后续迭代：动态竞争机制与日记Schema升级

### 动态竞争机制实施

**问题发现**：self_attack（强度公式：好奇+15）与 exploration（强度公式：好奇+10）永远差5点，导致 deterministic 竞争结果。

**解决方案**（三重机制）：

1. **多样性加成** (`_calculate_diversity_bonus`)
   - 追踪最近5次执行历史
   - 连续5次未执行 → +10~20随机加成
   - 执行1次 → +5~10小加成
   - 执行多次 → 无加成

2. **随机浮动** (±5)
   - 每个意图强度计算后添加 random.randint(-5, 5)
   - 打破固定差距

3. **平局处理** (久未执行者优先)
   - 强度相同时，比较最后执行位置
   - 更久没执行的意图排在前面

**关键测试**：
```
场景：最近5次都是 exploration
结果：self_attack 获得 +10~18 多样性加成

场景：最近5次都是 self_attack  
结果：exploration 获得 +11~20 多样性加成
选中：exploration (强度120)
```
