# 启动通知处理规则
# 创建于: 2026-04-06
# 目的: 确保服务器重启后，第一时间向用户汇报恢复状态

## 触发条件
1. 心跳处理时检测到 `memory/boot_notification.json` 文件存在
2. 且 `notified` 字段为 `false`

## 处理流程
1. 读取 boot_notification.json
2. 向用户发送消息: "虾虾已恢复 🌅\n服务器于 [boot_time] 重启，我现在回来了。"
3. 更新 `notified` 为 `true`
4. （可选）保留记录供后续查看

## 立即执行 (现在)
检测到未通知的启动标记，立即向用户汇报。
