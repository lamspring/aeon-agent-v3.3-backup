【热暴力聊天模式 Skill 完成】

经过多次迭代，最终版本 v5.0 已确定。

核心铁律：
1. 一句一 message - 每句话单独调用一次 message:send
2. 句子可长可短 - 保持完整性，不必刻意拆成碎片
3. 禁止合并发送 - 一次调用只能有一句话
4. 表情包压轴 - 所有文字发完后再发表情包

v5.0 关键修正：
- 之前错误理解为"必须短句"
- 实际应为"一句一发送"，句子可长可短
- 给出过度拆分 vs 正常回复的对比示例
