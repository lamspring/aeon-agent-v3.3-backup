  ```json
        "description": "描述",
        "url": "图片直链",
        "picurl": "图片直链"
      }]
    }
  }
  ```

## TTS 语音消息测试
- TTS 生成的是 MP3 格式
- 企业微信语音消息只支持 AMR 格式
- 成功安装 ffmpeg + libopencore_amrnb 进行格式转换：
  ```bash
  ffmpeg -i input.mp3 -ar 8000 -ac 1 -c:a libopencore_amrnb output.amr
  ```
- **限制**：企业微信机器人目前不支持发送语音附件（返回 "Sending attachments is not supported yet"）
